# Blog image manifest

All cover assets use the article slug as the filename and live under
`public/uploads/blog/`. The delivery format is 1200 x 630 WebP (1.91:1), with a
target file size below 180 KB. The focal subject stays inside the central 40%
of the canvas so the same image survives the desktop article's narrow crop and
the mobile article's wide crop.

Shared generation direction: photorealistic technical editorial photography;
electronics procurement and engineering context; deep navy, graphite and
restrained orange accents; realistic components and PCB materials; central
subject with useful surrounding texture; no readable text, logos, trademarks,
watermarks, fake part numbers or impossible pin geometry.
